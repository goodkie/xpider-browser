🤖 자동 캡차 해제 설정

음성 인식 CAPTCHA 자동 우회를 위해 Wit.ai Server Access Token이 필요합니다.

💡 무료 Wit.ai API Key 발급 방법
1. 아래 [무료 API 키 발급받기]를 클릭하여 로그인 (Facebook 연동)
2. 우측 상단 [Create App]을 클릭해 새 앱을 생성합니다 (이름은 자유)
3. 생성된 앱 좌측 메뉴에서 [Management] → [Settings]로 이동
4. 'Server Access Token'을 복사하여 아래 입력 칸에 붙여넣기
✅ 설정이 성공적으로 저장되었습니다!
